# Existing-feature design alignment: after-state evidence

Run `node scripts/capture-design-alignment.mjs` from the repository root to regenerate the PNG files and [`measurements.json`](./measurements.json). The harness starts Vite and the D23 test driver on temporary loopback ports, uses disposable project folders, exercises real application routes, and removes the fixtures and servers afterward. It records the source revision, any scenario failures, and computed DOM/CSS measurements for each screenshot. Set `EMEND_ALIGNMENT_OUTPUT` to capture in a temporary folder during development; `EMEND_ALIGNMENT_SCENARIO` filters by scenario name for a focused rerun.

The default viewport is 1400×900 CSS pixels at device scale 1, light color scheme. `Win32` and `MacIntel` platform overrides select Emend's platform styling before app modules load. The 3d, 9c, 9g, 13g and J9 held-route captures also use their named narrow widths. This is a **webview/browser visual gate**, not a native Tauri or operating-system frame capture. The final integrated pass captured **276 states with zero scenario failures** at revision `6df9ac1` (williacj/emend#11); the JSON names the exact full commit. The default pass now also runs the voice, compact-toolbar, composer voice error and 14b settings-controls scenarios, which have their own folders too. Screenshots retain the date-dependent card timestamps and saved-at readouts produced by the real fixture, so those strings are not pixel baselines.

## Verification and remaining differences

- Keyboard and honest-status coverage is in the integrated `e2e/acceptance.spec.mjs`: B4b overflow restores focus across width changes and executes relocated controls; B6 keeps the status line within narrow document columns; 13g asserts reason-first clipping and the 160px floor; the real Reload journey checks pending, failed and saved status; the document-delivery journey checks that typing focus, selection and editor scroll do not move. The 218-state capture adds visual evidence and computed geometry; it does not replace those behavior checks. Its J9 guard checks the actual backend requesting notice, exact line, one-line height, focusable Dismiss and retry-pending focus/busy state before each PNG. Its J10 guard checks that ordinary Reply and Address controls are absent during eligible Delete confirmation and that a withdrawn placeholder routes to the live passage. Its D27 guard checks that an omission-only tab retains its amber loss marker after refusal. Its core scenario guards against capturing pending changes as ordinary authoring and waits for a rendered insertion before capturing redline. Its JSON also records `role="status"` on the integrity banner, `aria-live="polite"`/`aria-atomic="true"` on the 13g band, focus within the blocked-Save banner, and focus on the fallback main root through pending and failed reload states.
- The [failed Reload capture](./win-11-failed-reload.png) now has only the mock's contextual amber failure line and status-bar readout. A separate reviewed D2 correction removed the duplicate app-wide generic error band. The fixture releases a held D23 `save_document` transport with a network failure, so the literal reason reads `Failed to fetch`; a real filesystem refusal would supply its own reason through the same contextual line.
- The [General Settings capture](./win-settings.png) now places the existing Light/Dark/System chooser at the top of the 1m content column and omits it from the title row. The Welcome fixture has no Recent entries and no installed writing partner, so those panels correctly show empty/disabled states instead of the mock's populated example.
- The Documents/Skills rail split and reachable comment-correction fragments have since shipped; their current evidence is in the [refresh (20) inventory](../design-alignment-refresh20.md) and [J10 captures](../alignment-refresh20-j10/README.md). The comments column, Timeline collapse, Share, Ask agent, attach/model/voice controls and project-home strip remain separate unbuilt capabilities. The existing mic and GitHub controls remain honestly disabled.
- Browser platform overrides cannot certify OS-owned title controls. Gate A2 checked the unsigned macOS Tauri overlay and native traffic-light lane; a native Windows runtime and its CI job remain outside this browser capture. The transient `11c.3` Reloading banner and J9 queued-suffix frame still lack deterministic production-browser images; their mounted state and announcement rules are covered by focused component tests. The J9 requesting and retry frames here use the real backend event stream with only its already published terminal transport held. No native title-control or pixel-parity claim is made for them.
