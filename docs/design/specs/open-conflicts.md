## The seven, and their dispositions

1. **D15 cannot be the durable provenance record.** The amendment ratified 2026-08-27 makes the scratch-adoption timeline card the durable post-adoption record. D15 says the transcript is scaffolding and explicitly not durable output. Making it durable — outbox, stable adoption id, awaited append, exactly-once — is a **D15 amendment**. The alternative, a document-attached provenance field, is the option that same amendment ruled out.
2. **The destructive override.** Ratified insertion ¶5 has it carry out the recorded closes without saving the session. The review is right that this is dishonest — the old session can restore them — but rewriting or removing that control revises ratified J2 wording.
3. **The empty-guard body.** *"…nothing has been written here since"* is ratified copy and is false after type-then-delete. The replacement is ratified-copy surgery.
4. **"Present and empty."** The ratified insertion asserts the over-cap document is empty; the code says it is empty only after relaunch. Splitting into `live-over-cap-not-durable` and `restored-omitted-empty`, and refusing to authorize close on backend `Ok(())`, reverses a ratified premise and re-couples quit to a guard J2 says it does not raise.
5. **The persistence receipt** changes the `save_tab_session` IPC contract and **FR-ED-3**. PR #1833 does not own the backend contract.
6. **Multi-window safety.** D26 grants ownership per **process**; there is no window-level guarantee to gate on. "Gate on enforced D26 single ownership" versus "require backend per-session-path serialization/CAS" is a **TD decision**.
7. **Active-run close refusal** composes FR-X-11's run-blocked close reporting into the D12 guard — behavior, J# territory.
